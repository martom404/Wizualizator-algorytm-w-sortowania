# Wizualizator algorytmów sortowania

Aplikacja webowa, która pokazuje krok po kroku, jak działają algorytmy sortowania. Każda operacja (porównanie, zamiana, zapis, przeniesienie do kubełka) jest widoczna na słupkach i opisana tekstem, a animację można zatrzymać, cofnąć i przewinąć.

## Uruchomienie

Wymagany [Node.js](https://nodejs.org/) w wersji 20.19 lub nowszej.

```bash
npm install
npm start
```

Aplikacja będzie dostępna pod adresem http://localhost:4200/.

| Polecenie | Działanie |
|---|---|
| `npm start` | serwer deweloperski z automatycznym przeładowaniem |
| `npm run build` | wersja produkcyjna w katalogu `dist/` |
| `npm test` | testy jednostkowe (Vitest) |
